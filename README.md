# 🎮 Simon Game 

A fun and interactive memory-based game built using **HTML, CSS, JavaScript, and jQuery**.  
Test your memory skills by following the sequence of colors and sounds!

---

## 🚀 Features

- 🎨 Color-based interactive game
- 🔊 Sound effects for each button
- 🧠 Increasing difficulty with each level
- ❌ Game over animation and restart feature
- ⚡ Smooth UI using jQuery event handling

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- jQuery

---

## 🎯 How to Play

1. Press any key to start the game.
2. Watch the pattern shown by the game.
3. Repeat the sequence by clicking the buttons.
4. Each level adds a new step to the sequence.
5. If you click the wrong button, the game ends.
